# ShadowUSB Glint — прототип Plymouth

Фон #101418 из общей палитры Matugen, неподвижный логотип, без надписей при обычной загрузке.
По поверхности снизу слева вверх направо проходит холодный мягкий блик:
3 секунды движения и 3 секунды паузы, независимо от boot progress.
Размер и положение вычисляются по размеру экрана.
Сообщения Plymouth и поля пароля/вопроса появляются только по запросу.

## Файлы

- `assets-src/logo.png` — исходный RGBA-логотип candidate-v2, без изменения формы.
- `generate-assets.py` — генератор на Python с Pillow и NumPy (только разработка).
- `assets/logo.png` — уменьшенная копия логотипа.
- `assets/glint-0.png` … `glint-23.png` — прозрачные слои света 640×640.
- `assets/entry.png` — рамка ввода.
- `shadowusb-glint.script` — Plymouth-анимация с интерполяцией между слоями.
- `shadowusb-glint.plymouth` — описание темы.
- `preview/preview.c`, `preview.sh` — отрисовка настоящим установленным script plugin
  Plymouth в память; без запуска демона, root, DRM/VT и изменения конфигурации хоста.
- `previews/` — результаты проверки, включая `shadowusb-glint.mp4`.

## Повторная генерация и preview

```sh
python3 generate-assets.py
bash preview.sh /tmp/shadowusb-glint-preview
bash preview.sh /tmp/shadowusb-glint-motion --motion
```

Для preview нужны компилятор C, pkgconf, библиотеки Plymouth и libpng.
Обычной загрузке нужны только `.plymouth`, `.script` и каталог `assets`.
Генератор, preview и его зависимости в initramfs не нужны.

## Проверка и ограничения

Проверены реальные отрисовки Plymouth для 1920×1080, 1920×1200,
1366×768 и 2560×1440; обычный режим, password/question/message callbacks.
MP4 собран из реальных PNG-кадров Plymouth с частотой захвата 10 кадров/с;
сама тема запрашивает 30 кадров/с. Это не видеозапись загрузки ISO.

24 слоя — небольшие локальные маски света, не полноэкранная видеопоследовательность.
Исходные маски в декодированном виде занимают около 38 MiB; Plymouth также хранит
масштабированные изображения и экранные буферы. Реальный расход зависит от экрана.

Первый вариант выбран для ArchISO. Тема хоста не изменяется.
DRM/KMS, initramfs, реальная скорость и передача экрана SDDM требуют boot test
после отдельной интеграции. Рабочая тема `shadowiso` не изменена.

Текущий preview helper захватывает движение с частотой 30 кадров/с.
Сохранённое видео первого варианта записано ранее с частотой 10 кадров/с.
Второй вариант блика и его preview удалены.

Пароль отображается графическими круглыми буллетами (assets/bullet.png), без текста запроса.
Длинный ввод ограничен видимым окном внутри рамки; пароль не обрезается.
Анимация при запросе пароля продолжается с обычной яркостью.
Сохранённое старое MP4 показывает прежний чёрный фон, не текущий запрос пароля.
